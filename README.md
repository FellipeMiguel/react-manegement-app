# React Management App

Este é um projeto de aplicação de gerenciamento desenvolvido com React. Ele foi criado para ajudar a organizar e gerenciar tarefas, projetos ou qualquer outro tipo de informação de forma eficiente.

## Funcionalidades

- Gerenciamento de tarefas/projetos.
- Interface amigável e responsiva.

## Tecnologias Utilizadas

- **React**: Biblioteca principal para construção da interface.
- **JavaScript/TypeScript**: Linguagem de programação.
- **TailwindCSS**: Estilização da aplicação.

## Como Executar o Projeto

1. Clone o repositório:

```bash
git clone https://github.com/FellipeMiguel/react-manegement-app.git
```

2. Navegue até o diretório do projeto:

```bash
cd react-management-app
```

3. Instale as dependências:

```bash
npm install
```

4. Inicie o servidor de desenvolvimento:

```bash
npm start
```

5. Acesse a aplicação no navegador:

```
http://localhost:5173
```
